# SEST CLI Tools

- [`check_sip_versions`](../../writing_tests/reference_specification.md) - A CLI tool to check the SHA values specified in SIP tests match the latest version from sila-chain/SIPs.
- [`sest`](sest.md) - A CLI tool that helps with routine tasks in sila-chain/execution-specs.
- [`sivm_bytes`](sivm_bytes.md) - Convert the given EVM bytes from a binary file or a hex string to SEST's python opcodes.
- [`extract_config`](extract_config.md) - Extract client configuration files (chainspec/genesis.json) from Sila clients via Hive.
